# Skillmatch Ai

Build FinGuide AI, a professional, mobile-friendly AI-powered opportunity discovery platform for students.



The goal is to help students find suitable hackathons, internships, competitions, and learning opportunities based on their skills, interests, education, and career goals.



Design:



- Modern navy blue, white, and teal colors

- Beautiful, professional dashboard

- Responsive layout for Android phones and computers

- Clean cards, icons, charts, and smooth navigation



Features:



1. Dashboard with welcome message and opportunity statistics.

2. Student profile form for skills, interests, education, and career goals.

3. Opportunity cards for hackathons, internships, competitions, and courses.

4. Personalized matching scores based on skill overlap and user interests.

5. Explanation of why each opportunity matches the student.

6. Search bar and category filters.

7. Save and unsave opportunities.

8. Application tracker with saved, planned, and applied statuses.

9. Deadline reminders displayed inside the app.

10. About page explaining the problem, solution, and impact.



Make all features functional, not just decorative. Store profile information and saved opportunities in browser local storage. Clearly label demo opportunities as sample data. Do not fabricate verified real-world opportunities.



Create a polished, working MVP suitable for demonstrating at HackNowa Global Hackathon 2026 under AI for Everyday Life. Prioritize functionality, originality, accessibility, and an excellent mobile experience.
